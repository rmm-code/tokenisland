# Roadmap

## MVP

- Buildable macOS SwiftUI app.
- Menu bar extra.
- Notch overlay and fallback positioning.
- Dashboard, settings, onboarding.
- SQLite storage.
- OTLP HTTP JSON receiver.
- OpenAI-compatible proxy scaffold.
- Unit tests for aggregation and normalization.

## v1

- Validate field mappings against live Claude Code and Codex telemetry.
- Add OTLP protobuf/gRPC support.
- Harden proxy support for streaming responses.
- Add materialized daily aggregates.
- Add CSV export.
- Add signed app bundle and notarization workflow.
- Add richer notification controls.

## Future

- Per-project budgets.
- Weekly/monthly trend views.
- IDE extension source tagging helpers.
- Shortcuts/App Intents.
- Optional iCloud sync for settings only.
